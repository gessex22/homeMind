# HomeMind — Informe de entrega (2026-11-04)

## Qué se entrega

Aplicación web local (Vite + Three.js) de navegación robótica simulada sobre un escaneo real de Polycam, con integración real de Meta Model API (Muse Spark 1.3 + SAM 3.1) para localizar un objeto visible y aproximarse a él usando solo el mapa descubierto.

Cuatro páginas compiladas en `dist/`:

| Página | Para qué |
|---|---|
| `index.html` | Laboratorio virtual: exploración por fronteras, keyframes, inventario, comparación de 10 pasadas |
| `motor.html` | Motor de navegación V2 reutilizable |
| `scan.html` | Visor del escaneo Polycam `10_28_2026.glb` (órbita, planta, corte, calibración de escala) |
| `scan-navigation.html` | Navegación sobre el escaneo real + análisis con Muse + SAM |

## Cómo ejecutarlo

Requiere Node.js 22.12+ y un navegador con WebGL 2.

```sh
npm ci
npm run dev        # desarrollo: incluye backend /api/ai/* para Meta
```

Abrir la URL que indique Vite (p. ej. `http://127.0.0.1:5173/scan-navigation.html`).

Para servir solo lo compilado: `npm run preview` (sin backend de IA; la página de navegación funciona, el análisis con Meta no).

Para configurar Meta, copiar `.env.example` como `.env`, añadir `MODEL_API_KEY` y reiniciar el servidor. También se acepta `META_API_KEY` o la API key local de Muse Code. La clave se lee únicamente en el servidor y no se incluye en Git ni en el paquete.

Repositorio de destino: https://github.com/gessex22/homeMind. GitHub Pages por sí solo permite servir la parte estática; la IA requiere ejecutar el backend con `npm run dev`.

## Qué demuestra esta entrega

- Exploración autónoma por fronteras con mapa de ocupación construido solo desde sensor virtual y odometría (con ruido, fusión de movimiento, scan matching y SLAM 2D experimental opcionales).
- Navegación sobre la malla real escaneada, sin precargar la geometría como mapa del planificador.
- Análisis RGB real con Muse + SAM: máscara del objeto, posición estimada con profundidad virtual y aproximación por ruta sobre el mapa descubierto.
- Destino manual sobre suelo descubierto, conducción manual, recuperación ante suelo no verificado y exportación JSON de mapa/resumen.

## Limitaciones honestas (no incluidas)

- Sin hardware real: todo es simulación sobre el escaneo; no demuestra acoplamiento ni carga en un cargador físico.
- Sin inventario semántico persistente con identidad fusionada entre capturas; el alcance actual es un objeto visible en la vista presente.
- Sin estimación de orientación funcional del objeto; si el objetivo no está a la vista, falta exploración guiada por la solicitud.
- La calibración de escala del escaneo es manual (baldosa de 32,7 cm) y su precisión depende de la selección.
