# HomeMind — Delivery note

November 4, 2026 · [Repository](https://github.com/gessex22/homeMind)

## Current demo

A browser prototype where a simulated robot explores a scanned room, builds a map and moves toward manually selected destinations. Object recognition with Muse Spark and SAM is in development. Initial real API tests exist, but recognition and its connection to navigation are not fully integrated or validated as a complete workflow.

The room's source 3D reconstruction was created with Polycam, an external tool, and is used as a prepared environment for study and development. HomeMind builds its own navigation map from simulated readings. Reconstructing the environment directly with the robot's own physical sensors is future work.

The AI calls are real. The camera view, distance readings and robot movement come from the simulation. The demo still requires user supervision and may stop with parts of the room unexplored.

## Intended outcome

A reusable autonomy capability for physical robots, with potential applications in patrols, inventory tasks and returning to charge when the battery is low. Completing the recognition-to-navigation integration, validating on hardware and developing these task applications remain future work. Battery-triggered return, docking and charging have not been demonstrated.

See the [README](README.md) for setup and the [saved AI observation](docs/meta-ai-evidence.json) for a previous real Meta API result.

Delivery checks passed: **236 automated tests and a successful build**, including validation on GitHub. These checks verify software behavior; they do not demonstrate performance on a physical robot. No new live AI calls were made during delivery preparation.

The repository includes the source, room scans and setup instructions. The delivery ZIP also includes the compiled application. The experimental AI integration requires a Meta API key and the local service started with `npm run dev`.
